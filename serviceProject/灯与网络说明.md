# 主机 (LED 主控) — 灯带与网络说明

pio run -t upload --upload-port /dev/cu.usbmodem2301
pio device monitor --port /dev/cu.usbmodem2301

## 一、硬件与灯带

| 项目       | 说明 |
|------------|------|
| 灯带类型   | WS2812B，GRB 顺序 |
| 数据引脚   | GPIO2（代码 `LED_PIN`） |
| 灯珠数量   | **460**（代码 `NUM_LEDS`，约 92 颗/米 × 5m；按实际焊接颗数修改） |
| 默认亮度   | 50（0–255，代码 `BRIGHTNESS`） |
| OLED       | SSD1306 128×64 I2C，SDA=GPIO10、SCL=GPIO20，地址 0x3C |
| 蜂鸣器     | 压电片，GPIO21（方波驱动） |
| GPIO7 按键 | 双短按=重置游戏；三连击=详细日志；按住 2~5s=OLED 调试；满 5s=强制离线重启 |
| GPIO8/GPIO9 | 游戏速度 +1 / −1（档位 1~30，默认 15；映射电脑出点间隔 5000ms→400ms） |

主机无独立“状态灯”，所有状态均通过**灯带效果**表示。

## 二、玩法与灯带状态含义（Dot 波次版）

游戏核心在 `src/game/`（`game_manager` 状态机 + `color_stream` 每局随机 7 色序列 + `collision_manager` 同色反向消除）。

| 灯带效果 | 含义 |
|----------|------|
| **蓝呼吸** | **搜索开关 A/B**：等待无线开关上线，双开关都发现后进入“就绪” |
| **彩色流水** | **双开关就绪**（IDLE）：**仅按开关 A 可开始游戏** |
| **光点移动** | 游戏进行中（攻防发射）：电脑严格定时从 0 端出点（颜色入积压队列）；玩家 A/B 严格交替按键——有积压时跟队头最旧色防守对撞，积压清空后取预告色进攻推进 |
| **全彩波浪** | WIN：从 0 端和末端同时向中间爆发全彩波浪，汇合后全场高亮炫彩闪烁 |
| **全红闪烁** | LOSE：电脑点到达末端（配下沉音阶） |
| **黄色呼吸** | PAUSE：A/B 链路抖动暂停，恢复后自动继续 |
| **黄色/绿色/蓝色进度条/红色** | OTA 更新中/完成/进度/出错 |

**颜色同步（COL）**：主机在游戏状态/轮次/**目标色**变化时向 A/B 下发 `COL+H,S,V+meta`（meta 低 bit=该开关可按，高 4bit=GameState），并每 2s 刷新兜底抗丢包。目标色 = 积压队头最旧（防守）或色流预告色（进攻）。开关灯环：轮到本开关=目标色呼吸，非本回合=暗红微光，暂停=琥珀呼吸。

**调色板（4 套主题，每局随机）**：经典彩虹 7 色 / 赛博霓虹 6 色 / 暖阳热带 5 色 / 冰雪极光 5 色；每次发射在实际色相上 ±5 随机微抖（视觉更有质感），同色碰撞判定仍按颜色序号，不受微抖影响。

**蜂鸣器音效（无阻塞序列器）**：开局上爬音阶 / 发射短哔 / 碰撞下降音 / 按错低沉双响 / 胜利大三和弦号角 / 失败下沉音阶，详见 HANDOFF.md §5.2。

**离线判定**：开关每 2s 心跳（PA/PB）；35s 无包判单端离线→游戏 PAUSE；双端同时离线满 90s 清除配对回到搜索。

## 三、网络与配网

### 3.1 配网（首次或换 WiFi）

- **AP 名称（SSID）**：`Service-Setup`，密码 `setup1234`
- 配网页面：连上 AP 后打开 `http://192.168.4.1/config`（首页 `/` 为状态页）

### 3.2 连上家里 WiFi 之后

- **主机名（mDNS）**：`ESP32-C3-LED`
- 状态页（含运行日志）：`http://ESP32-C3-LED.local/status`
- OTA 上传：项目目录执行 `make ota`（OTA 密码 `12345678`）

### 3.3 离线模式

无路由器时主机自动进入 AP 配网模式并**仍启用 ESP-NOW**（AP 信道 1）；GPIO7 满按 5s 可强制离线重启（NVS 持久化）。

## 四、ESP-NOW 通信可靠性（2026-09 更新）

解决“稍远/轻微遮挡就丢包”的三端协同改造：

| 机制 | 端 | 说明 |
|------|-----|------|
| 关闭 WiFi 省电 | 三端 | `esp_wifi_set_ps(WIFI_PS_NONE)`，modem sleep 是丢包主因 |
| 满发射功率 | 三端 | `esp_wifi_set_max_tx_power(84)` |
| LR 长距离协议 | 三端 | `ENABLE_ESPNOW_LR=1`（约 +10dB 链路预算）；**三端必须同时开启**，与路由器 STA 可共存 |
| 单播优先 | A/B | 开关从主机定向消息学习主机 MAC，按键/心跳改单播（驱动层有 ACK 重试） |
| 关键消息重发 | 双向 | 主机→开关双发；开关→主机按键三连发；接收端 250ms 去重防重复触发 |
| 心跳广播兜底 | A/B | 每 5 次心跳或主机 12s 无消息时补广播，主机 MAC 变化后自愈 |
| BSSID/信道对齐 | A/B | HTTP 拉取主机 `/espnow-info` 对齐（游戏进行中自动跳过，降低按键延迟） |

**消息协议**：开关→主机 `A`/`PA`/`B`/`PB`/`RST`/`RST!`；主机→开关 `ACK_A`/`ACK_B`/`RDY`/`TA`/`TB`/`BAD`/`WIN`/`GOF`/`COL`。（旧 `CD` 倒计时消息已废弃删除）

## 五、串口命令（调试用）

接 USB 串口时可输入：

- `1` 全部点亮 / `2` 逐个点亮 / `3` 游戏模式
- `set` 重置游戏
- `brightness <0-255>` 亮度
- `status` 状态
- `debug on/off` OLED 调试；`verbose on/off` 详细日志；`espnow on/off` 收包 hex 调试

**重置途径汇总**：开关双击 `RST`（限 IDLE/WIN/LOSE/PAUSE）｜开关长按 2 秒 `RST!`（任意状态）｜主机 GPIO7 双短按。
