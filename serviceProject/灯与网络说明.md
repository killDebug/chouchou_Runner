# 主机 (LED 主控) — 灯带与网络说明

pio run -t upload --upload-port /dev/cu.usbmodem2401

pio device monitor --port /dev/cu.usbmodem2401
## 一、硬件与灯带

| 项目       | 说明 |
|------------|------|
| 灯带类型   | WS2812B，GRB 顺序 |
| 数据引脚   | GPIO2（可在代码中修改 `LED_PIN`） |
| 灯珠数量   | 默认 480（5 米 × 96 灯/米，可在代码中修改 `NUM_LEDS`） |
| 默认亮度   | 50（0–255，代码中 `BRIGHTNESS`） |

主机无独立“状态灯”，所有状态均通过**灯带效果**表示。

---

## 二、灯带状态含义

| 灯带效果           | 含义 |
|--------------------|------|
| **蓝呼吸**         | **搜索开关 A/B**：等待无线开关 A、B 上报，双开关都发现后自动进入“就绪” |
| **彩色流水**       | **双开关就绪**：A、B 均已发现，主机定期发 ACK_A（A 灯环绿）、RDY（B 灯环彩色流水）；**仅按开关 A 可开始游戏**，B 不能开始 |
| **游戏进行中**     | 灯带上有点从 A 端向 B 端移动，需在开关 A 灯环上按对应颜色消除；倒计时、胜利/失败等由主控控制灯带与 A/B 灯环 |
| **全部白 / 逐个点亮** | 串口或无线命令 `1` / `2` 的测试模式（非日常游戏） |
| **黄色**           | OTA 更新开始 |
| **绿色**           | OTA 更新完成（约 2 秒） |
| **蓝色进度条**     | OTA 传输中进度 |
| **红色**           | OTA 出错 |

**超时**：双开关就绪后，若 60 秒内未再收到 A 或 B 的报文，主机会回到“搜索 A/B”状态（灯带重新变为蓝呼吸），并清除已记录的 A/B 地址。

## 三、网络与配网

### 3.1 配网（首次或换 WiFi）

- **AP 名称（SSID）**：`Service-Setup`
- **AP 密码**：`setup1234`
- **配网页面**（手机/电脑连上 `Service-Setup` 后打开浏览器）：
  - `http://192.168.4.1/` — 填写家里 WiFi 的 SSID 和密码，保存后设备重启并尝试连接

### 3.2 连上家里 WiFi 之后

- **主机名（mDNS）**：`ESP32-C3-LED`
- **访问方式**（与主机在同一 WiFi 的电脑/手机）：
  - **状态页（含运行日志）**：`http://ESP32-C3-LED.local/status`
  - **OTA 上传**：在项目目录执行 `make ota`（目标为 `ESP32-C3-LED.local`，无需记 IP）

### 3.3 在配网 AP 模式下看状态

- **状态页**：`http://192.168.4.1/status`

## 四、状态页与“网页看串口”

- 打开 **`http://ESP32-C3-LED.local/status`**（或 AP 模式下 `http://192.168.4.1/status`）。
- 页面显示：主机名、WiFi、当前模式、主机状态、开关 A/B 是否发现、**ESP-NOW 收包数**、最近按下、LED 数量与亮度、配网提示等。
- **重要**：主机必须与开关 **连同一 WiFi（STA）** 才能收到 A/B。若主机当前是 **AP 模式**（未配网或连不上路由器），页面上会红字提示，且 **不会初始化 ESP-NOW**，收包数始终为 0。请先配网让主机连上家里 WiFi，再用同一网络访问状态页。主机端会添加广播 peer（FF:FF:FF:FF:FF:FF）才能接收开关发来的 ESP-NOW 广播包。
- **最近运行日志**：页面下方有“最近运行日志（相当于串口输出）”区域，显示最近约 40 条日志（启动、WiFi、ESP-NOW、OTA、开关上线/超时等），**无需接 USB 串口**即可查看。
- 日志区域**每 1 秒自动更新**（通过 AJAX 请求 `/log`，只刷新日志区，不整页重载）。
- 若需仅获取纯文本日志，可访问：`http://ESP32-C3-LED.local/log`（或 AP 下 `http://192.168.4.1/log`）。

## 六、OTA 密码与注意事项

- **OTA 密码**：`12345678`（在代码中设置，与 ArduinoOTA 一致）
- **OTA 时不要按开关**：上传过程中 WiFi 忙于 OTA，若此时按 A/B，可能造成上传失败或设备无响应，属于正常现象；上传完成后再按即可。

## 七、串口命令（调试用）

接 USB 串口时可输入：

- `1` — 全部点亮模式  
- `2` — 逐个点亮模式  
- `3` — 游戏模式  
- `brightness <0-255>` — 设置灯带亮度  
- `status` — 在串口打印当前状态  
- **`espnow` 或 `espnow on`** — 开启 ESP-NOW 收包调试：之后收到的每个包会打印 **raw len + hex**，用于验证开关 B（或 A）是否真的发到主机；`espnow off` 关闭。

无线开关 A 发 `A`、开关 B 发 `B`，主机会记录并显示在状态页“最近按下”；仅按 **A** 可开始游戏。若主机一直显示“未发现 B”，可先串口输入 `espnow`，再按 B，看是否出现 `[ESP-NOW raw] len=1 hex=42`（42 即字符 'B'），有则说明通讯正常、问题在识别逻辑；没有则说明主机未收到 B 的包（距离/信道/程序跑飞等）。
