# ESP32 音效包说明

## 原包问题
- 未压缩 wav 合计约 14MB（tar.gz 约 8.3MB）
- edge-tts 人声尾部常有约 0.9～1.2 秒静音

## 本目录已处理
- 去掉首尾静音（尾部保留约 20ms，防爆音）
- 转单声道，降采样，重打包

## 三种规格（文件名与原先一一对应）

| 规格 | 目录/压缩包 | 大致体积 | 建议用途 |
|------|-------------|----------|----------|
| pcm16k | `esp32-pcm16k.tar.gz` | 见压缩包 | 音质较好，I2S 播 PCM；适合外挂 Flash / SD |
| pcm8k | `esp32-pcm8k.tar.gz` | 更小 | 小 Flash；人声 8kHz 会略糊但仍可懂 |
| adpcm16k | `esp32-adpcm16k.tar.gz` | 约 PCM 的 1/4 | 省空间；需固件支持 IMA-ADPCM 解码 |

## ESP32 能不能存下？
要看板子 Flash，不是看压缩包名义大小：

- **4MB Flash**：程序占掉后，LittleFS/SPIFFS 往往只剩 **约 1～2MB**，**塞不下全套 149 条**。
- **8MB Flash**：若划出 3～4MB 给资源，可用 **adpcm16k** 或 **只放高频短音 + 关键人声**，全量仍紧。
- **16MB Flash** 或 **SD 卡**：全量 **pcm16k** 通常可行。
- 很多玩具方案：**音频放 SD**，Flash 只放固件。

## 实用建议
1. 优先用去静音后的包（本包）。
2. 全量上板：SD 或 16MB + adpcm/pcm8k。
3. 若只有 4MB：按事件做「精简集」（每类 1～2 条随机即可），体积可压到 1MB 级。
