# 开关 B 电路与 GPIO 说明

## 功能

开关 B 是一块 **ESP32-C3 Super Mini**，通过 **ESP-NOW** 向主机（serviceProject 灯带主控）发消息：

- **短按**：发送 `"B"`（三连发抗丢包，主机 250ms 窗口去重），主机识别为开关 B 按下
- **每 2 秒心跳**：发送 `"PB"`，主机用于在线检测
- **450ms 内双击**：发送 `"RST"`（仅 IDLE/WIN/LOSE/PAUSE 状态主机接受）
- **长按 2~5 秒**：发送 `"RST!"`（主机任意状态强制重置游戏，对战卡死脱困用）
- **长按 5 秒**（开发值，正式版 30 秒）：进入模式选择（1=调试 2=重置WiFi 3=关机 4=伴睡）

> 注意：游戏**开局只能由开关 A 发起**（IDLE 状态按 B 无效）；对战中 A/B 按轮次（TA/TB）轮流按键。
> 开关 B 与开关 A 代码几乎相同，仅身份不同（B/PB/ACK_B/主机名/AP 名）；B 已同步 A 的 mDNS 自动重试。

**ESP-NOW**：低延迟、设备直连、可不依赖路由器。学到主机 MAC 后改**单播**发送（驱动层有 ACK 重试），广播仅作兜底。

## 接线（当前代码为准）

| 功能 | GPIO | 说明 |
|------|------|------|
| **按钮** | **GPIO2** | 另一端接 GND，内部上拉，按下为 LOW |
| **中间白色指示灯** | **GPIO3** | PWM：常亮=WiFi 已连 / 呼吸=调试模式 / 慢闪=AP 配网 / 快闪=未连网 |
| **灯环数据线** | **GPIO4** | WS281x 灯环 12 颗（5050，GRB），VCC 接 5V，GND 共地 |
| 板载蓝灯 CD2 | GPIO8 | 上电/运行指示（睡眠前熄灭）；板载红灯 CD1 建议焊掉省电 |

> 历史版本曾用 GPIO4 做按钮、发送 "3"，已废弃；现在按钮固定 GPIO2，灯环 GPIO4。

### 注意点

- **GPIO0**：Boot 按钮，不要用作游戏开关。
- **GPIO2/3/4/8 已占用**，扩展外设请用其它空闲 GPIO。

## 与主机的通信可靠性（2026-09 更新）

| 机制 | 说明 |
|------|------|
| 关闭 WiFi 省电 | `esp_wifi_set_ps(WIFI_PS_NONE)`，modem sleep 是 ESP-NOW 丢包主因之一 |
| 满发射功率 | `esp_wifi_set_max_tx_power(84)` |
| LR 长距离模式 | 802.11 LR 协议（`ENABLE_ESPNOW_LR`），**三端必须同时开启**；与路由器 STA 可共存 |
| 单播优先 | 收到主机 ACK/RDY/TA/TB/WIN/GOF/COL 后学习主机 MAC，按键/心跳改单播 |
| 关键消息三连发 | 按键 A/B、RST、RST! 连发 3 次（间隔 30ms），主机 250ms 去重 |
| 心跳广播兜底 | 每 5 次心跳或主机 12s 无消息时补一包广播，主机 MAC 变化后可自愈 |
| BSSID 对齐 | 每 15s HTTP 拉取主机 `/espnow-info` 对齐信道/BSSID（游戏进行中自动跳过，降低按键延迟） |
