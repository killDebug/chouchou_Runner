# 开关 A 电路与 GPIO 说明

## 功能

开关 A 是一块 **ESP32-C3 Super Mini**，通过 **ESP-NOW** 向主控（灯带控制器）发消息。  
按下物理按钮时，向主控发送命令 `"3"`，主控进入游戏模式。

**ESP-NOW**：低延迟、设备直连、可不依赖路由器；比 UDP 更适合按钮类控制。

---

## 开关电路（推荐接法）

### 元件

- 1× 无锁按钮开关（轻触开关 / 自复位）
- 2 根杜邦线（或导线）

### 接线

| 按钮引脚 | 接到 |
|----------|------|
| 一端     | **GPIO4**（ESP32-C3 Super Mini 板子上的 GPIO4 焊盘/排针） |
| 另一端   | **GND**（板子上的 GND） |

- 使用 **内部上拉**，不需要外接电阻。  
- **不按**时：GPIO4 被拉高为 **HIGH**。  
- **按下**时：GPIO4 接 GND，为 **LOW**。  
- 代码里检测 **下降沿**（从 HIGH 到 LOW）并做消抖，避免一次按下触发多次。

### 示意

```
ESP32-C3 Super Mini
        ┌─────────────┐
  GPIO4 ├──●         │
        │   │ 内部上拉
  GND   ├──┴──────────┤
        └─────────────┘
             │
             │ 两根线
             ▼
        ┌─────────┐
        │  按钮   │
        │  ○   ○  │
        └─────────┘
         一脚接 GPIO4
         另一脚接 GND
```

## GPIO 说明（本开关 A 使用）

| 用途     | GPIO | 说明 |
|----------|------|------|
| **按钮** | **4** | 接按钮一脚，另一脚接 GND，使用 `INPUT_PULLUP`，按下为 LOW。 |

### ESP32-C3 Super Mini 注意点

- **GPIO0**：通常为 Boot 按钮，不建议再作游戏开关，以免进入下载模式。
- **GPIO2**：部分板子接板载 LED，若主控项目已用 GPIO2 驱动灯带，则开关板不用 GPIO2 即可。
- 本方案仅用 **GPIO4** 做开关输入，其它 GPIO 可留给以后扩展（例如开关 B 用 GPIO5）。

如需改用其它 GPIO，在 `src/main.cpp` 中修改：

```cpp
#define BUTTON_GPIO 4   // 改成你实际接的 GPIO 编号
```

## 主控与开关的配合

1. **主控**（serviceProject）：开启 **ESP-NOW 接收**，收到字符串 `"1"` / `"2"` / `"3"` 等与串口命令一样处理。
2. **开关 A**（本工程）：开启 **ESP-NOW 发送**，按下按钮向**广播地址**发送 `"3"`（游戏模式）；主控在同一 WiFi 信道内即可收到，**无需配置主控 IP**。
3. 两者可连同一 WiFi（便于 OTA），也可不连路由器，只要在 ESP-NOW 通信范围内即可。

## 可选：外接 LED 指示

若想在按下时点亮一颗 LED：

- LED 正极 → 限流电阻（约 220Ω～1kΩ）→ **GPIO5**（或其它空闲 GPIO）。
- LED 负极 → GND。
- 代码中在该 GPIO 上 `digitalWrite(pin, HIGH)` 点亮，`LOW` 熄灭。  
当前工程未接 LED 也可正常使用。

---

## 小结

- **开关电路**：按钮一脚接 **GPIO4**，另一脚接 **GND**，使用内部上拉，按下为 LOW。  
- **GPIO**：本开关只用到 **GPIO4**；若换引脚，改 `BUTTON_GPIO` 并重新烧录即可。
