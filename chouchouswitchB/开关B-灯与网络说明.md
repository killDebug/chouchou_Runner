# 开关 B (SwitchB) — 灯状态与网络说明

## 一、硬件引脚
ls /dev/cu.*

| 功能       | 引脚   | 说明 |
|------------|--------|------|
| 中间白灯   | GPIO3  | 普通 LED，表示 WiFi 状态 |
| 按钮       | GPIO2  | 另一端接 GND，内部上拉，按下为低电平 |
| 灯环数据线 | GPIO4  | WS281x 灯环（12 颗，5050，GRB） |

---

## 二、灯状态说明

### 2.1 中间白色灯（GPIO3）

| 状态     | 含义 |
|----------|------|
| **常亮** | WiFi 已连接（STA 已连上家里路由器） |
| **呼吸**（明暗渐变循环） | **调试模式已开启**，便于确认进入成功 |
| **慢闪**（约 0.5 秒一次） | 处于**配网 AP 模式**（请连 `SwitchB-Setup` 用网页配 WiFi） |
| **快闪**（约 0.15 秒一次） | WiFi 未连接且不在配网模式（如路由器关、密码错等） |

### 2.2 灯环（WS281x，GPIO4）

灯环显示有优先级：**模式选择**（黄/蓝）> 主控同步 > 游戏/上线 > WiFi 状态 > 串口测试模式。

| 灯环效果           | 含义 |
|--------------------|------|
| **全绿约 2 秒**    | 收到主控 `ACK_B`，表示“与主机连接成功” |
| **主控目标色**     | 主控发来 `COL`，显示当前要按的颜色（游戏进行中） |
| **全红约 8 秒**    | 主控发来 `GOF`，游戏失败 |
| **红→黄→绿 3 秒** | 主控发来 `CD`，倒计时 |
| **全绿约 4 秒**    | 主控发来 `WIN`，本波全部消除胜利 |
| **蓝色闪烁**      | **配网 AP 模式**：请连 WiFi `SwitchB-Setup` 去配网 |
| **红色呼吸**      | **WiFi 未连接**（且不在 AP 模式），提示网络异常 |
| **全黄**          | **模式选择**：长按 30 秒后进入，再按 1/2/3 下 + 5 秒确认选模式 |
| **蓝灯个数**      | 模式选择中：按几下亮几颗蓝灯（1=调试 2=重置 3=关机 4=伴睡）；按到 13 下为 11 蓝+1 异色，再按从 1 重计 |
| **彩色流水+呼吸** | **夜间伴睡模式**：彩虹流水灯，整体亮度缓慢呼吸；20 分钟无操作自动进入深度睡眠 |
| **黄色**          | OTA 更新进行中 |
| **绿色**          | OTA 更新完成（约 2 秒） |
| **蓝色进度条**    | OTA 传输中进度 |
| **红色**          | OTA 出错 |
| 串口测试模式      | 发 `1` 全白、`2` 彩虹、`3` 逐个、`4` 关灯（仅当无主控动画且未显示 WiFi 状态时） |

## 三、网络连接与配置地址

### 3.1 配网（首次或换 WiFi）

- **AP 名称（SSID）**：`SwitchB-Setup`
- **AP 密码**：`setup1234`
- **配网页面**（手机/电脑连上 `SwitchB-Setup` 后打开浏览器）：
  - `http://192.168.4.1/` — WiFi 配置页（填家里 WiFi 的 SSID 和密码，保存后设备会重启并连接）

### 3.2 连上家里 WiFi 之后

- **主机名（mDNS）**：`ESP32-C3-SwitchB`
- **访问方式**（电脑/手机需与开关在同一 WiFi）：
  - **状态/调试页**：`http://ESP32-C3-SwitchB.local/status`
  - **OTA 上传**：在项目目录执行 `make ota`（platformio.ini 里已配置为 `ESP32-C3-SwitchB.local`，无需记 IP）

### 3.3 若在配网 AP 模式下也要看状态

- **状态页**：`http://192.168.4.1/status`

## 四、模式选择（调试 / 重置 / 关机）

所有特殊模式**统一入口**：**长按 30 秒** → 灯环变**黄**，进入“模式选择”；然后**短按次数**选择，**5 秒内无操作**即确认。

| 短按次数 | 灯环示意     | 5 秒无操作后 |
|----------|--------------|--------------|
| **1 下** | 亮 1 颗蓝灯  | **调试模式** 开/关切换 |
| **2 下** | 亮 2 颗蓝灯  | **重置 WiFi**：清除配置、重启进配网 AP |
| **3 下** | 亮 3 颗蓝灯  | **关机**：进入深度睡眠，再按按钮可唤醒 |
| **4 下** | 亮 4 颗蓝灯  | **夜间伴睡模式** 开/关：灯环彩色流水 + 呼吸 |
| 不按     | 保持全黄     | 取消，恢复常态 |
| 5 下以上 | 5～12 颗蓝灯 | 5 秒后取消（不执行任何模式） |
| 13 下    | 11 蓝 + 1 异色 | 再按从 1 重计；5 秒后取消 |

- 进入模式选择后，只有**短按**（轻点）才计数，长按松手不计数。
- 日常使用不会误触：需要刻意长按 30 秒才会进入。

### 4.2 不连 USB 看“串口输出”

- 用按键序列**开启调试模式**后，打开 **`http://ESP32-C3-SwitchB.local/status`**。
- 页面会多出一块 **「最近运行日志」**，相当于串口输出（最近 40 条），例如：
  - 启动信息、WiFi 连接结果、OTA 状态、ESP-NOW 发送、调试模式开关等。
- **开启调试模式后，日志区域每 1 秒自动更新**（通过 AJAX 只拉取日志，不整页刷新），无闪烁、响应更快。
- **未开启调试模式**时，状态页只显示运行状态，不显示日志块，也不会自动更新。

## 七、省电与睡眠（无需额外开关）

- **条件**：**未开启调试模式**，且**超过 5 分钟**既没有按过按钮、也没有收到主机的 ACK（即没有和主机联系）。
- **行为**：设备会**自动进入深度睡眠**（耗电极低）。此时灯环和白灯都会灭。
- **唤醒**：**按一下同一颗按钮**（GPIO2）即可唤醒，设备重新上电启动、连 WiFi、恢复正常工作。**不需要再加一个电源开关**，就用这一颗按钮即可“关机/开机”。
- **手动关机**：通过**模式选择**（长按 30 秒 → 黄灯 → 按 3 下 → 5 秒）进入深度睡眠，再按一下按钮即可唤醒。
- **调试模式**：只要**开启了调试模式**，就**不会自动睡眠**，会一直运行，方便你随时看状态和日志。
- **夜间伴睡模式**：开灯后** 20 分钟无按键**视为已睡着，会自动进入深度睡眠（灯灭），再按按钮可唤醒。

| 情况           | 是否会自动睡眠 |
|----------------|----------------|
| 未开调试 + 长时间无主机且无按键 | 会（约 5 分钟无活动后） |
| 模式选择 → 3 下 | 会（手动关机） |
| 已开调试       | 不会自动睡眠（可经模式选择关机） |
| 夜间伴睡模式   | 会（20 分钟无操作后自动睡眠） |
| 最近有主机 ACK 或按过键 | 不会自动睡眠 |

## 八、关于板载 PW 灯与原理图（ESP32-C3 Super Mini）

根据你提供的原理图：

- **CD1（红）**：阳极接 3.3V，阴极接 GND，有电就亮、一直耗电。**可以直接焊掉**：CD1 只是 3.3V 上的一个负载，焊掉后**不会影响 3.3V 或 LDO**，只是少了一个用电器，更省电。
- **CD2（蓝）**：阴极接 **GPIO8**，程序可控制。固件已用它做**上电/运行指示灯**：运行时蓝灯亮，进入深度睡眠前蓝灯灭，既省电又能看出当前是开机还是关机。

**推荐**：焊掉红灯 CD1，用蓝灯 CD2 表示上电状态即可，无需改线。

**长按 10 秒松手就开机的问题**：原因是进入深度睡眠时**手指还按着按钮**，GPIO2 一直是 LOW，而唤醒条件正好是“GPIO 为 LOW”，所以一进睡眠就被判定为唤醒，立刻又开机。固件已改为：长按满 10 秒后**先等按钮松开**，再进入深度睡眠；这样松开后设备会真正睡下去，下次**再按一下**才会唤醒。
